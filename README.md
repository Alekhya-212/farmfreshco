# FarmFreshCo – Hosting Website on Linux with Apache

## 📌 Overview
FarmFreshCo is a sample business website hosted on a **Linux machine using Apache HTTP Server**.  
This project demonstrates how to deploy and serve static web content with Apache.

---

## ⚙️ Prerequisites
- Linux machine (Ubuntu/RHEL/CentOS recommended)
- Apache HTTP Server installed
- Git installed
